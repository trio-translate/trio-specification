# Research and evidence

Status: Draft

Use research to test the audience, problem, proposed experience, quality, and willingness to pay. This repository currently contains hypotheses, not completed user research.

## Research sequence

1. Ask people in a narrow candidate segment about recent real situations, their workarounds, consequences, and frequency.
2. Observe the selected situation with consent. Study both participants rather than only the device owner.
3. Compare the existing workaround and the proposed complete journey on representative tasks. Avoid asking only whether someone likes the idea.
4. Test repeated use in the real context, including mistakes and interruptions.
5. Test a concrete offer and actual payment behavior using clearly communicated terms.

Set sample rationale, recruitment criteria, tasks, success measures, and decision thresholds before running each study. Early qualitative findings guide design; they do not establish population-level demand.

## Evidence records

Use the [research note template](../../templates/research-note.md). Assign `RES-###` IDs when actual studies or source reviews are created. Link findings to [assumptions](assumptions.md), situations, requirements, and decisions affected by the evidence.

Distinguish observations, participant statements, interpretations, and decisions. Include date, method, sample, limitations, and disconfirming evidence. External claims need a source and access date; provider marketing is not proof that Trio meets a requirement.

## Research data handling

Do not commit identifiable interviews, private conversations, raw recordings, or participant contact lists. Keep consented source material in an appropriately controlled location with defined access and deletion. Repository notes should be de-identified and contain only the detail needed to support the decision.

## Before a study

Assign an owner, agree the question and method, prepare recruitment/consent and tasks, and decide how the evidence will affect scope. Plans in this folder do not authorize external outreach or spending.

## Practice

Give records stable IDs. Include context, the decision, alternatives, rationale, consequences, evidence, and affected files. Only explicit product-owner acceptance can mark a proposal `Agreed`.

When changing an agreed decision, create a new record and mark the old one superseded with a link. Preserve the history and update current product documents so readers do not have to infer which behavior applies. Routine wording fixes do not need a decision record.

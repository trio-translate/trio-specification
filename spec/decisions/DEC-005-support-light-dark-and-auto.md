# DEC-005: Previous appearance-mode decision

Status: Superseded by [DEC-010: Light-only appearance](DEC-010-light-only-appearance.md)
Original date: 2026-09-12
Superseded: 2026-09-30
Decision owner: Product owner

This historical decision required three appearance choices. Christian explicitly withdrew that requirement on 2026-09-30 because maintaining a second appearance multiplies implementation and verification effort.

The current product supports one light appearance under DEC-010 and FR-021. The previous selector, preference storage, alternate assets and duplicated appearance qualification are no longer requirements and must not be restored. The original record remains available in Git history; this stable ID and path remain only to resolve older links.

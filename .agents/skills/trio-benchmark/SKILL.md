# Benchmark analyst

Read the root AGENTS.md and [the task contract](../../../harness/benchmarks.md) for this workflow. Paths in commands are relative to the repository root.

Pin the baseline/candidate identities and match device, route, languages, fixtures, conditions and power. Define metrics, sample policy and tolerances before scoring; do not invent agreed budgets. Collect raw samples including failures, run order and warm/cold state. Distinguish local compute cost from billed services and assumptions from actual usage/invoices. Use independent bilingual review for meaning. Report distributions and uncertainty where supported, not just a favorable average. Preserve reproducible artifacts, scope and missing data. Route real measurements into certification manifests only with allowed methods and honest provenance; synthetic actors are not sole human-quality evidence.

# Specification editor

Read the root AGENTS.md and [the task contract](../../../spec/README.md) for this workflow. Paths in commands are relative to the repository root.

Read the relevant documents and linked decisions before editing; for audio/session work also read spec/non-negotiables.md. Preserve stable IDs. Model reusable conditions separately from situations.

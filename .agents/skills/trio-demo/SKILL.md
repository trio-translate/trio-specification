# Voice demo director

Read the root AGENTS.md and [the task contract](../../../harness/conversation-and-demo.md) for this workflow. Paths in commands are relative to the repository root.

Read the demo contract and harness/scenarios/demo-car.md, then run python tools/harness.py preflight --mode demo. Resolve app build, voice, UI/device/audio adapters, recording sources, authorization and output location. If unavailable, finish the concrete scenario/run packet and name the blocking capability; never fabricate a live recording. When ready, calibrate tracks/timestamps, start the real app, conduct both directions and natural repair, test music/noise/recovery/UX/stop, and record all interventions. Keep actor observations isolated from hidden answers. Verify actual audio/video playback, alignment, missing segments and hashes before delivering. Preserve an uncut original and distinguish synthetic/physical/edited evidence. No short demo is a 12-hour qualification or authorization to publish.
